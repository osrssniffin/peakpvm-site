What is Peak PvM?

Peak PvM is a Discord first OSRS PvM community built around finding teams, learning content, organizing runs, and having more people to play with. We focus on raids, bossing, events, and community without elitist requirements or unnecessary hierarchy.

Features

PvM Party Finder

Role pings for ToA, CoX, ToB, Nex, Yama, Corp, Nightmare, BA, Learners, and more.

PvM Scheduler

Set up raids and bossing runs now or later.

Community Hiscores

Synced with Wise Old Man to follow the community’s progress.

Easy RSN Sync / Onboarding

Sync your RuneScape name and get settled into the server.

Loot Tracking & OSRS Utilities

Track drops, check game status, catch TL;DR game updates, and use other handy OSRS tools built right into the server.

Community PvM Events

Boss of the Week, PvM Bingo, competitions, and more as the server grows.
